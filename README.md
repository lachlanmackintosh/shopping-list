# Shopping

Lockie's weekly shopping list. Static HTML, CSS, and JavaScript — no build step, no accounts. After the first visit it works offline, and it can be added to an iPhone Home Screen as **Shopping**.

Edit the items in [`data.js`](data.js). The first option on an item is the gold-standard default. Ticks, option choices, and one-off items stay in the browser.

https://lachlanmackintosh.github.io/shopping-list/
