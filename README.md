# Shopping

Lockie's weekly shopping list. Static HTML, CSS, and JavaScript — no build step, no accounts. After the first visit it works offline, and it can be added to an iPhone Home Screen as **Shopping**.

Edit the items in [`data.js`](data.js). Rows show a short label and quantity; the product, price, links and notes sit in each item's options (first option = the pick). Personal care and Supplements have Lockie and Margo sub-lists. The Rules tab reads from `RULES` in data.js. Ticks, option choices, and one-off items stay in the browser.
